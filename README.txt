GALLERY PHOTOS
==============
Put photos in the matching folder, named with numbers starting from 1:

  nature/         1.jpg, 2.jpg, 3.jpg ...
  landscape/      1.jpg, 2.jpg, 3.jpg ...
  architecture/   1.jpg, 2.jpg, 3.jpg ...
  travel/         1.jpg, 2.jpg, 3.jpg ...
  islamic/        1.jpg, 2.jpg, 3.jpg ...

- The website finds them automatically. No code change needed.
- Numbers must be continuous (1, 2, 3 ... no gaps). If 4 is missing, 5 and later will not show.
- Small letters only. .jpg, .jpeg, .png or .webp all work.
- Tip: width about 1600px, under 300 KB each. Keep your originals elsewhere.
